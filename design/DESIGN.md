# 색감 사진관 (FilmLook Studio) 디자인 가이드

| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.1 (2026-11-25) |
| 변경 내용 | v1.1: PRD v1.4 반영. 기본값과 사용자 LUT 칸(`U01`), B 테마 높이 제한, 두 단계 공유, 단축키 포커스 규칙, C 테마 `--color-highlight` 대비 수정, 파일 경로 정정 |
| 기준 시안 | `design/mockups/색감사진관-시안A-darkroom.html`, `색감사진관-시안B-camera.html`, `색감사진관-시안C-pastel.html` |
| 관련 문서 | `docs/FilmLook Studio PRD.md` v1.4 (기능 요구 사항), `CLAUDE.md` (개발 규칙) |

이 문서는 디자인 시안 3종을 실제 앱으로 구현하기 위한 규칙입니다. 시안과 이 문서가 다르면 **이 문서가 우선**이고, 이 문서와 PRD가 다르면 기능은 PRD, 모양은 이 문서를 따릅니다.

---

## 1. 디자인 원칙

1. **사진이 주인공입니다.** 장식은 사진 바깥에만 둡니다. 미리보기 테두리 안쪽(사진과 맞닿는 면)은 무채색 또는 흰색입니다.
2. **테마는 옷일 뿐입니다.** 세 테마는 같은 컴포넌트, 같은 상태, 같은 동작을 공유합니다. 테마가 바꾸는 것은 ① 디자인 토큰, ② 문구, ③ 장식 요소 세 가지뿐입니다.
3. **기믹은 하나씩, 결과에는 영향 없이.** 테마마다 기믹 토글이 하나 있으며, 화면 분위기만 바꾸고 저장 결과는 바꾸지 않습니다.
4. **아날로그의 은유를 기능 이름에 씁니다.** 강도는 ‘노광 타이머’, ‘조리개’, ‘말랑 강도’처럼 테마의 언어로 부르되, 숫자 값과 기본 이름(강도, 입자)은 항상 함께 보여 줍니다.
5. **접근성은 테마보다 앞섭니다.** 모든 테마에서 글자 대비 4.5:1 이상, 터치 영역 44px 이상, 키보드 조작과 포커스 표시를 지킵니다.

## 2. 시안 파일 보는 법

| 파일 | 내용 |
|---|---|
| `mockups/색감사진관-시안A-darkroom.html` | A 암실: 데스크톱 화면 + 스마트폰 화면 |
| `mockups/색감사진관-시안B-camera.html` | B 카메라 기어: 데스크톱 화면 + 스마트폰 화면 |
| `mockups/색감사진관-시안C-pastel.html` | C 파스텔 사진관: 데스크톱 화면 + 스마트폰 화면 |
| `mockups/sample-photo.svg` | 시안용 예시 사진(일러스트). 실제 앱의 샘플 사진은 본인 촬영 JPEG로 교체 |

- 시안은 브라우저로 열면 프리셋 선택, 비교 슬라이더, 강도·입자·흑백 필터, 기믹 버튼이 실제로 움직입니다.
- **시안의 색 변화는 CSS `filter`로 흉내 낸 것입니다.** 실제 앱은 WebGL2 캔버스와 3D LUT로 처리합니다(PRD 6장). 시안의 필터 값을 프리셋 값으로 옮기지 마세요.
- 시안의 초기값(강도 80, 입자 20, 비교 위치 50)은 시연용입니다. 앱의 기본값은 3.3 표를 따릅니다(강도 100, 비교 위치 0, 입자는 프리셋 기본값).
- 시안에는 **테마 전환 버튼이 없습니다.** 위치와 모양은 이 문서 6.3을 따릅니다.
- 시안에 없는 화면: 사진이 없을 때의 첫 화면(사진 열기·샘플 사진), 드래그 앤 드롭 표시, 원본 보기 버튼(E-04), 저장 진행·공유 단계, 오류·경고 안내, 앱 정보(비제휴 고지), .cube 불러오기, 태블릿 배치. 이 화면들은 각 테마의 기존 토큰·컴포넌트로 만들고, 처음 만들 때 스크린숏을 `design/screenshots/`에 남깁니다.

## 3. 화면 구조 (세 테마 공통)

### 3.1 영역

| 영역 | 역할 | 들어가는 컴포넌트 |
|---|---|---|
| 헤더 | 앱 이름, 전역 동작 | `Logo`, `GimmickToggle`, `ThemeSwitcher`, `OpenButton`, `SaveButton` |
| 밀착 인화 | 프리셋 8칸 고르기 | `ContactSheet` > `Frame` × 8 |
| 미리보기 | 결과 확인과 비교 | `Preview` > `CompareSlider`, `GrainOverlay`, `PresetCaption` |
| 조절판 | 값 조절과 저장 | `StrengthControl`, `GrainControl`, `MonoFilterPicker`, `SaveCard` |

### 3.2 반응형 배치

| 구간 | 너비 | 배치 |
|---|---|---|
| 데스크톱 | 1200px 이상 | 3열: 밀착 인화 300~340px · 미리보기(나머지 전부) · 조절판 300~360px. 열 사이 간격 28~36px, 좌우 여백 40~44px |
| 태블릿 | 768~1199px | 2열: 미리보기 · 조절판. 밀착 인화는 미리보기 아래 가로 스크롤 줄 |
| 스마트폰 | 767px 이하 | 1열: 헤더(고정) → 미리보기 → 프리셋 정보 → 밀착 인화 가로 줄 → 조절 → 저장(하단 고정) |

- 데스크톱의 가운데 열은 `flex: 999 1 600px`처럼 남는 폭을 모두 차지하게 하고, 미리보기는 `aspect-ratio: 3/2`로 폭에 맞춰 커집니다. 화면이 넓을수록 사진이 커져야 합니다.
- **B 테마 예외:** 데스크톱에서 밀착 인화는 화면 아래 전체 폭의 필름 스트립(8칸 1줄, 사용자 LUT가 있으면 9칸)입니다. 왼쪽 열에는 카메라 일러스트, 장전된 필름 카드, 현재 값 요약을 둡니다.
- **B 테마 높이:** 1440×900에서 페이지 스크롤 없이 헤더·뷰파인더·LCD 줄·필름 스트립이 모두 보여야 합니다. 뷰파인더에 `max-height: calc(100dvh - 헤더 - LCD 줄 - 필름 스트립 - 여백)`을 주고, 3:2 비율은 유지한 채 폭을 줄여 가운데 정렬합니다. 높이가 더 낮은 창에서는 페이지 스크롤을 허용합니다.
- 스마트폰에서는 가운데 영역만 세로 스크롤합니다. 밀착 인화 줄만 가로 스크롤을 허용하고 스크롤바는 숨깁니다.

### 3.3 공통 상태 (모든 테마가 같은 이름을 씀)

| 상태 | 값 | 기본값 | 설명 |
|---|---|---|---|
| `preset` | `ORIG`, `P01`, `V02`, `A03`, `C04`, `N05`, `E06`, `M07`, `U01` | `ORIG` | 선택한 프리셋. `U01`은 사용자 LUT를 불러왔을 때만 존재 |
| `strength` | 0~100 | 100 | 강도. 0이면 입자도 넣지 않음 |
| `compare` | 0~100 | 0 | 비교 경계선 위치(%). 왼쪽 원본, 오른쪽 결과. 0이면 사진 전체가 결과. 사진을 새로 열면 0으로 돌아감 |
| `grain` | 0~100 | 프리셋의 `defaultGrain` | 입자 양. 프리셋을 고를 때마다 그 프리셋의 기본값으로 바뀜(M07은 25, 나머지·원본·`U01`은 0) |
| `mono` | `none`, `yellow`, `red`, `green` | `none` | 흑백 필터. `preset`이 `M07`일 때만 활성 |
| `gimmick` | true / false | false | 테마 기믹 켜짐 여부. 테마를 바꾸면 false로 초기화 |
| `theme` | `darkroom`, `camera`, `pastel` | `camera` | 현재 테마. 브라우저에 기억 |

시안 코드의 `cmp`, `gim`, `mono: 'N'|'Y'|'R'|'G'`는 위 이름으로 바꿔 구현합니다.

## 4. 디자인 토큰

### 4.1 구조

- 루트 요소에 `data-theme="darkroom|camera|pastel"`을 붙이고, 토큰은 CSS 변수로 정의합니다.
- 컴포넌트는 **의미 토큰만** 씁니다(`--color-accent`). 색상값(`#ff4b3a`)을 컴포넌트에 직접 쓰지 않습니다.
- 기믹 상태는 `data-gimmick="on"`으로 표시하고, 토큰을 덮어써서 표현합니다(예: A 테마 작업등).

## 5. 문구 사전 (테마별)

같은 기능을 테마의 말투로 부릅니다. 문구는 `src/themes/<테마>/copy.ts`에 두고, 컴포넌트는 키로만 참조합니다.

| 키 | A 암실 | B 카메라 기어 | C 파스텔 사진관 |
|---|---|---|---|
| `sheet.title` | 밀착 인화 | (필름 스트립, 제목 없음) | 밀착 인화 스티커 |
| `sheet.hint` | 마음에 드는 컷에 그리스 펜슬로 동그라미를 칩니다. | — | 마음에 드는 스티커를 콕 눌러 주세요 |
| `open` | 사진 열기 | 사진 넣기 | 사진 열기 |
| `save` | 인화하기 · JPEG 저장 | 저장 (셔터 버튼) | 사진 뽑기 · 저장 |
| `strength` | 강도 · EXPOSURE TIMER | 강도 · APERTURE | 말랑 강도 |
| `grain` | 입자 | 입자 · GRAIN DIAL | 보슬보슬 입자 |
| `mono.title` | 흑백 필터 젤 | 렌즈 필터 | 흑백 사탕 필터 |
| `mono.items` | 없음·노랑·빨강·초록 | 없음·Y2(노랑)·R25(빨강)·G11(초록) | 없음·레몬 노랑·딸기 빨강·멜론 초록 |
| `mono.disabled` | M07 전용 | M07 흑백 전용 | 모노 그레인 전용 |
| `compare.left` / `right` | 노광 전 · 원본 / 현상 후 · 코드 | ORIGINAL / 코드 · 강도% | 원래 사진 / 프리셋 이름 |
| `compare.hint` | 사진 위를 좌우로 끌면 원본과 비교됩니다 | 사진을 좌우로 끌어 비교 | 곰돌이를 좌우로 밀어 비교해 보세요 |
| `gimmick` | 작업등 켜짐/꺼짐 | 격자선 켜짐/꺼짐 | 반짝이 켜짐/꺼짐 |
| `save.info` | JPEG 92% · 원본 해상도 · EXIF·GPS 유지 | JPEG 92% · GPS 유지 | JPEG 92% · 원본 크기 · 위치 정보 그대로 |

## 6. 공통 컴포넌트 규칙

### 6.1 밀착 인화 칸 (`Frame`)

- `<button type="button">`으로 만들고, `aria-pressed`로 선택 여부를, `aria-label`로 “V02 비비드 슬라이드 선택”을 제공합니다.
- 내용: 썸네일(프리셋 적용, 강도 100%), 프레임 번호, 프리셋 이름.
- 썸네일은 긴 변 512px 축소본에 프리셋을 적용한 캔버스 이미지입니다(PRD 6.2). 사진을 바꿨을 때만 다시 만듭니다.
- 선택 표시는 테마별로 다릅니다(7장). 선택 변화는 0.25초 안에 끝나는 전환 효과로 보여 줍니다.
- **사용자 LUT 칸(`U01`):** .cube를 불러오면 마지막에 9번째 칸이 붙습니다. 프레임 번호는 `09`, 이름은 파일 이름(확장자 제외, 길면 말줄임), 부제는 “사용자 LUT”입니다. 칸 안에 작은 ‘빼기’ 버튼(`aria-label`: “사용자 LUT 빼기”)을 둡니다. A·C의 2열 격자는 5행이 되고, B 스트립은 9칸, 스마트폰 가로 줄은 9칸이 됩니다.

### 6.2 미리보기와 비교 슬라이더 (`Preview`, `CompareSlider`)

- 미리보기 비율은 3:2를 기본으로 하되, 실제 사진 비율(세로 사진 포함)에 맞춰 `object-fit: contain`처럼 여백을 둡니다. 여백 색은 `--color-preview-mat`입니다.
- 비교는 사진 전체를 덮는 투명한 `<input type="range">`로 구현합니다(시안 방식). 접근 이름은 “원본과 결과 비교 위치”, 키보드 `←`/`→`로 5%씩 움직입니다.
- 경계선 손잡이는 테마별 모양이지만 크기는 지름 36~62px, 끄는 동작을 방해하지 않도록 `pointer-events: none`입니다.
- 기본 위치가 0(왼쪽 끝)이므로, 경계선은 왼쪽 끝에 붙되 손잡이는 사진 안쪽으로 밀어 넣어 반쯤 잘리지 않게 합니다. 이때 비교 안내 문구(`compare.hint`)를 함께 보여 줍니다.
- 사진 위의 라벨(원본/결과)은 반투명 바탕 위 글자로, 사진 색과 상관없이 읽혀야 합니다.
- 입자(그레인)는 미리보기에서는 결과 쪽에만 겹쳐 보이고, 저장 시에는 셰이더에서 원본 픽셀 좌표 기준으로 넣습니다(PRD 6.3).

### 6.3 테마 전환 (`ThemeSwitcher`) — 시안에 없는 요소

- 위치: 헤더 오른쪽, ‘사진 열기’ 버튼 바로 왼쪽. 스마트폰에서는 헤더 아이콘 버튼 줄의 첫 번째.
- 모양: 지름 44px 원형 버튼 안에 현재 테마의 견본(A 붉은 원, B 금속·주황 원, C 분홍·민트 반반 원). 누르면 세 테마 견본과 이름이 있는 작은 메뉴가 열립니다.
- 메뉴는 `<button>` 목록으로 만들고, 현재 테마에 체크 표시와 `aria-checked`를 둡니다. `Esc`로 닫고, 단축키 `T`로 다음 테마로 넘어갑니다.
- 테마를 바꿀 때 편집 상태(`preset`, `strength` 등)는 그대로 두고 `gimmick`만 꺼집니다. 0.3초 배경색 전환 외의 애니메이션은 넣지 않습니다.

### 6.4 조절 컨트롤

- 강도·입자는 `<input type="range">` + `<label>` + 현재 값 표시입니다. 값 표시는 슬라이더 옆이나 위에 항상 보입니다.
- 슬라이더 색은 `accent-color: var(--color-accent)`로 지정합니다. 트랙 높이 28~30px로 터치하기 쉽게 합니다.
- 흑백 필터(`MonoFilterPicker`)는 4개 버튼입니다. `preset`이 `M07`이 아니면 묶음 전체를 `opacity: .35~.4`, `aria-disabled="true"`로 두고 안내 문구(`mono.disabled`)를 보여 줍니다. 실제 `disabled` 속성도 함께 줍니다.

### 6.5 저장 (`SaveButton`, `SaveCard`)

- 주 버튼은 화면에 한 종류의 강조색으로만 존재합니다(헤더 저장 + 조절판 저장은 같은 동작).
- 저장 중에는 버튼 문구를 `save.progress`(“인화 중… 37%”)처럼 진행률로 바꾸고, 다른 조작을 막습니다(PRD S-06).
- 저장 정보(`save.info`)는 버튼 바로 아래 또는 위에 작은 글씨로 둡니다.
- **두 단계 공유(PRD S-04):** Web Share API로 파일을 공유할 수 있는 기기에서는, 렌더링이 끝나면 같은 자리의 버튼이 `share`로 바뀌고 `share.hint`를 보여 줍니다. 한 번 더 누르면 공유 시트가 열립니다. 공유 시트를 닫거나 편집 값을 바꾸면 버튼은 다시 저장으로 돌아갑니다. 공유를 지원하지 않는 기기는 렌더링이 끝나자마자 바로 다운로드합니다.
- 스마트폰 해상도 상한(PRD 6.3)에 걸리면 저장 전에 `save.downscaled`를 저장 정보 자리에 보여 줍니다.

### 6.6 키보드 단축키

- `1` 원본, `2`~`8` P01~M07, `9` 사용자 LUT(있을 때), `\` 원본 보기(누르고 있는 동안), `Ctrl+S` 저장, `←`/`→` 비교 위치 5%씩, `T` 다음 테마(M5부터).
- 포커스가 `<input>`(슬라이더 포함)이나 메뉴 안에 있으면 그 요소가 키를 먼저 씁니다. 숫자·`T`·`\` 단축키는 동작하지 않고, `←`/`→`는 포커스된 슬라이더 값을 바꿉니다. `Ctrl+S`는 언제나 동작합니다.

### 6.7 아이콘과 일러스트

- 아이콘은 선 굵기 1.6~2.6px의 인라인 SVG로 만들고, 이모지는 쓰지 않습니다.
- 장식 SVG에는 `aria-hidden="true"`, 의미가 있는 일러스트(B 테마 카메라)에는 `role="img"`와 `aria-label`을 붙입니다.
- 일러스트는 `src/themes/<테마>/art/`에 React 컴포넌트로 둡니다. 색은 토큰을 씁니다.

| 선택 전환 | 공통 | 0.25초 | 선택 표시 등장 |

- `prefers-reduced-motion: reduce`이면 반복 애니메이션과 등장 효과를 모두 끄고, 선택 전환만 즉시 바뀌게 합니다.
- 애니메이션은 `transform`과 `opacity`만 움직입니다. 미리보기 캔버스 자체에는 CSS 필터 애니메이션을 걸지 않고, 등장 효과는 캔버스를 감싼 요소에 겁니다.

## 10. 접근성 체크리스트

- [ ] 모든 버튼은 `<button>`, 모든 슬라이더는 `<input type="range">` + `<label>`
- [ ] 아이콘만 있는 버튼에 `aria-label`
- [ ] 선택한 프레임은 `aria-pressed="true"`, 테마 메뉴 항목은 `aria-checked`
- [ ] 포커스 표시: A·B 강조색 2px 실선, C 자주색 3px 점선, 바깥쪽 3px 띄움
- [ ] 터치 영역 44×44px 이상(스마트폰 밀착 인화 칸 포함)
- [ ] 글자 대비 4.5:1 이상(4.4 표)
- [ ] 비활성 흑백 필터는 `disabled` + 안내 문구
- [ ] `prefers-reduced-motion` 대응
- [ ] 색만으로 상태를 구분하지 않음(선택 = 모양 표시 + 굵기 변화)

## 11. 새 테마를 추가하거나 고칠 때

1. `src/themes/<이름>/tokens.css`에 4.2의 의미 토큰을 **모두** 정의합니다.
2. `copy.ts`에 5장의 키를 모두 채웁니다.
3. 장식 컴포넌트(`art/`)는 기능 컴포넌트 밖에 둡니다. 기능 컴포넌트에 테마 이름으로 분기하는 코드(`if (theme === 'pastel')`)를 쓰지 않고, 장식을 끼우는 자리(slot)로 받습니다.
4. 4.4 표에 대비 값을 추가합니다.
5. 데스크톱 1440×900과 스마트폰 390×844에서 세 가지 작업(프리셋 고르기 → 비교 → 저장)이 되는지 확인하고, 스크린숏을 `design/screenshots/`에 남깁니다.
